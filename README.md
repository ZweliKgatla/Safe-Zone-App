SafeZone

SafeZone is a safety monitoring system designed to help parents and guardians keep track of their loved ones. The system alerts a user when a connected person moves beyond a predefined safe distance, helping reduce the risk of children getting lost or separated.

Features

- Set a custom safe distance.
- Receive alerts when the safe distance is exceeded.
- Real-time distance monitoring.
- Designed to be simple, reliable, and easy to use.
- Can be demonstrated using two smartphones connected to the same application.

Project Purpose

The goal of SafeZone is to improve personal safety by providing an affordable and accessible proximity monitoring solution. Although the initial focus is on children, the concept can also be adapted for elderly family members, people with disabilities, lone workers, and individuals travelling alone.
